# 🐍 Python Programming Practice: Loops & Conditionals

A repository of iterative algorithm practice problems, nested control flow routines, and mathematical pattern generators written in Python.

---

## 📌 Repository Overview

This repository documents dedicated programming practice to build algorithmic intuition:
- `questions using loop and conditionalstatment.ipynb` — Nested `for` and `while` loop iterations, condition filtering, and accumulator patterns.
- `practice quetions.ipynb` — String manipulations, number reversal, and prime verification algorithms.
- `practice questions 2.ipynb` — List transformations, dictionary frequency mappings, and edge-case handling.

---

## ⚙️ How to Run

Launch in Jupyter Notebook or VS Code to run and test exercises interactively:
```bash
jupyter notebook
```
